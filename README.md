# Customer-Data-EDA
Customer data analysis using Python, Pandas and Numpy

## Project Overview

This project analyzes customer data using Python to identify missing values, patterns, and customer segments.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Key Activities

* Data cleaning and handling missing values
* Exploratory Data Analysis (EDA)
* Customer behavior analysis
* Data visualization and statistical summaries

## Objective

To understand customer data and extract meaningful insights through data analysis.
